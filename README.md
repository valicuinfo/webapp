
# Sistem Înscriere Palatul Copiilor

## Instalare

1. Creează baza de date `palat_inscrieri`
2. Importează fișierul `init.sql`
3. Completează conexiunea DB în `config/config.php`
4. Accesează un formular: `http://localhost/webapp/public/formular.php?targu-jiu`
5. Admin panel: `http://localhost/webapp/admin/login.php`
